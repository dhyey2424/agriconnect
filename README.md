# AgriConnect V2 — Full Interactive Prototype

## What changed
The original V1 homepage is preserved as-is. V2 adds the complete demo ecosystem:
- Farmer dashboard
- 4-step listing journey
- Market price intelligence
- AI-assisted visual assessment
- Verified listing/publish state
- Buyer marketplace
- Produce detail + bidding
- Farmer bid comparison + net realization
- Deal confirmation / transaction receipt
- Buyer dashboard
- Technology + Maharashtra pilot roadmap

## Open locally
Open `index.html` in a browser. Navigate through the top navigation or demo buttons.
